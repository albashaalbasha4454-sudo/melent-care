# MELENT CARE — Client Handover Specification

## 1. Project Identity

Project name: **MELENT CARE Exhibition Booth**

Project type: L-shaped exhibition booth.

The booth is designed as a corporate healthcare and medical tourism stand. It should not appear as a perfume shop, retail cosmetic shop, or overloaded product display.
